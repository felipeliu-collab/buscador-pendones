Buscador de Pendones

Encuentra menciones de pendón, pendones, roller y mini pendón en los datos importados, incluidos sus ítems y descripciones.

Cobertura limitada: no es un buscador nacional completo.

Esta versión busca solo en los archivos consultados o importados. Si la fuente omite ítems, las menciones presentes únicamente en ellos no podrán encontrarse. La ausencia de resultados no significa que no existan oportunidades.

No se consultan portales privados, no se eluden controles ni se inventan resultados. Las condiciones de uso y los permisos de cada fuente deben permitir su consulta.

Consultar datos oficiales

Usa una exportación autorizada de Datos Abiertos de ChileCompra o de Mercado Público. Consulta el formato admitido en el README del repositorio.

Con archivo: se busca en su contenido; la procedencia es declarada por ti y no se verifica. Sin archivo: se intenta descargar el JSON o CSV público de la URL. No se interpretan páginas HTML ni se consulta una API nacional preconfigurada.
